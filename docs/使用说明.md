# TimbreCanvas 使用说明

## 1. 第一次安装

在终端进入 TimbreCanvas 仓库，运行：

```bash
./script/setup.sh
```

首次配置需要下载并转换多个模型，耗时取决于网络和 Mac 性能。脚本可重复执行；已验证的下载会复用，不需要每次重新获取。

如果内部磁盘空间有限，可把运行时和模型安装到外置磁盘：

```bash
./script/setup.sh --install-root "/Volumes/ExternalAI/TimbreCanvas"
```

App 默认安装在 `$HOME/Applications`。如需安装到其他目录：

```bash
./script/setup.sh --app-dir "/Applications"
```

## 2. 主界面

左侧是音色库，中间是文本和情绪控制，底部是生成结果。

1. 在左侧选择一个官方示例或自建音色。
2. 在文本区输入中文或英文内容。
3. 调整情绪、情绪强度、语速；需要时展开高级设置。
4. 选择导出目录。
5. 点击生成。模型首次加载会比后续生成更久。

窗口顶部状态显示“模型已就绪”后即可正常生成。App 会保持一个常驻推理进程，避免每次重新加载模型。

## 3. 音色

### 使用官方示例

首次安装会从 IndexTTS 2 官方演示仓库下载 11 个示例声音，并在本机生成对应音色文件。它们会出现在“官方示例”分组。

### 克隆自己的音色

1. 点击音色库中的导入按钮。
2. 选择一段清晰、单人、背景噪音较少的音频。
3. 输入音色名称，等待提取完成。
4. 新音色会保存到本地“自建音色”分组。

只使用你本人或已取得明确授权的声音。不得用克隆音色冒充他人、欺骗或侵犯隐私。

### 重命名与删除

- 在音色行的菜单中选择“重命名”即可修改显示名称。
- 自建音色可删除；官方示例不可删除，但可重命名显示名称。
- 删除自建音色时，只会移除 TimbreCanvas 自己管理的音色文件，不会删除原始导入文件。

## 4. 预设

预设保存以下内容：

- 当前音色
- 8 维情绪与情绪强度
- 语速
- 温度、Top P、Top K、重复惩罚
- 扩散步数、CFG、随机种子
- 分段长度、停顿和重叠等高级参数

调好参数后点击“保存预设”，输入名称。之后选择预设即可一次恢复整套生成配置。预设可以重命名或删除。

## 5. 可调参数

| 参数 | 作用 | 建议 |
| --- | --- | --- |
| 情绪向量 | 控制开心、愤怒、悲伤、害怕、厌恶、低落、惊讶、平静 | 总体保持克制更自然 |
| 情绪强度 | 决定情绪条件的影响程度 | 通常不高于 0.8 |
| 语速 | 不改变音高地调整播放速度 | 先在 0.85–1.15 间尝试 |
| Temperature | 控制随机性 | 越高变化越大，也越不稳定 |
| Top P / Top K | 限制采样候选 | 默认值适合大部分文本 |
| 重复惩罚 | 减少重复片段 | 过高可能影响自然度 |
| 扩散步数 | 控制声学采样质量与耗时 | 越高通常越慢 |
| CFG | 控制条件引导强度 | 过高可能出现失真 |
| Seed | 固定随机过程 | 需要复现时填写 |
| 分段参数 | 控制长文本切分、停顿与衔接 | 长文出现断裂时再调整 |

界面已经覆盖当前 IndexTTS 2 MLX 适配器对用户开放的全部生成参数。模型内部调试参数没有暴露，以免产生无效或不安全组合。

## 6. 文件位置

默认情况下：

- App：`$HOME/Applications/TimbreCanvas.app`
- 本地配置：`$HOME/Library/Application Support/TimbreCanvas/config.json`
- 运行时与模型：`$HOME/Library/Application Support/TimbreCanvas`

选择外置安装目录时，配置仍保留在 Application Support，模型、缓存、音色和预设位于你选择的位置。配置文件权限为仅当前用户可读写。

## 7. 常见问题

### 模型不可用

重新运行 `./script/setup.sh`。脚本会验证 Python、IndexTTS 2 文件、转换后权重和官方示例声音。它不会接受 IndexTTS 1.5 文件。

### 外置磁盘未连接

重新连接原磁盘后启动 App，或重新运行安装脚本并选择新的安装位置。

### 第一次启动很慢

第一次需要从磁盘载入数 GB 权重并初始化声码器。常驻进程就绪后，后续生成无需重复加载。

### App 被系统阻止

源码构建版本使用本机临时签名，未经过 Apple 公证。可在“系统设置 → 隐私与安全性”确认你信任自己构建的 App。公开分发仍需开发者签名和公证。

## 8. 移除

退出 TimbreCanvas，将 `TimbreCanvas.app` 移到废纸篓。若还要释放模型空间，再手动移除安装时选择的 TimbreCanvas 目录。删除前请先备份自建音色和预设。
